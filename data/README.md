# Data

Raw data is not committed. The notebook downloads it into `data/raw/` on first run.

Source: Hourly PM2.5 from the Copernicus Atmosphere Monitoring Service (CAMS) global analysis and daily weather from the ECMWF ERA5 reanalysis, both through the open [Open-Meteo API](https://open-meteo.com/) (CC BY 4.0). 374,640 hourly values for ten cities, August 2022 to November 2026.
